### setup

1. Need docker desktop installed
2. Need C# IDE
3. Need react skills

### Running

1. `bash docker-compose up -d`
2. Run Graphql Server `dotnet run --project=GraphQLServer`
3. Run the admin Frontend `cd Frontend/admin && npm i && npm run dev`
